# 01 - Azure Foundation

## Lab resources

- Resource Group: ariws-rg-lab
- Region: Switzerland North

## Concepts
**Subscription** is the main Azure administration and billing boundary.

**Resource Group** is a logical lifecycle container for related resources.

**Region** is the Azure geography where resources are deployed.

**Tags** help organize ownership, environment, project and cost.

## Cost lesson
When the VM is Stopped (deallocated), compute billing stops. Persistent resources such as managed disks and some IP/network resources can still incur charges.
